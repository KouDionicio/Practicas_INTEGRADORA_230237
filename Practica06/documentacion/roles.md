# Roles representados

## Lector / usuario

Usuario de la aplicación móvil Lezhin Comics que descubre y consume cómics/webtoons. Los sketches le atribuyen acceso, registro, exploración, búsqueda, resultados, episodios y lectura; también muestran biblioteca, favoritos, monedas, historial y perfil/configuración. Estas tareas se describen a partir de las etiquetas de las pantallas, sin afirmar el comportamiento de una aplicación funcional.

Pantallas: R01–R07, R09–R15 (14 únicas). La pantalla 08 no se encuentra en los assets. No se muestra selección de rol.

## Administrador / editor

Usuario con acceso administrativo para operar el catálogo y la plataforma. Los sketches muestran dashboard, menú, gestión/búsqueda/alta/edición de cómics, alta de episodios, gestión de usuarios y categorías, estadísticas y configuración.

Pantallas: A01–A07, A09, A11a, A11b, A12–A15 (14 únicas). Las pantallas 08 y 10 no se encuentran. El número 11 aparece dos veces en la lámina y se distingue mediante sufijos. A12 tiene una discrepancia entre su título y los campos dibujados.

## Compartidas

No se identificaron pantallas compartidas explícitas. Los accesos y perfiles son distintos por rol. No se añadieron pantallas compartidas por suposición.
