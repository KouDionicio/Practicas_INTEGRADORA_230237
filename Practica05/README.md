# Práctica 05: Diagrama de Roles de Usuarios

## Proyecto Integrador

**Actividad:** Diagrama de Roles de Usuarios para el Proyecto Integrador  
**Valor:** 15 firmas  
**Fecha de entrega:** 07 de octubre de 2026  
**Modalidad:** En equipo  

---

## Descripción

En esta práctica se desarrollará un **Diagrama de Roles de Usuarios** correspondiente al Proyecto Integrador.

El objetivo es identificar y representar visualmente los diferentes tipos de usuarios que interactúan con la plataforma, describiendo las responsabilidades y acciones que puede realizar cada rol.

Además, se deberán identificar al menos **5 funcionalidades principales (features)** que serán desarrolladas dentro de la plataforma, estableciendo una relación entre los usuarios y las funcionalidades que tendrán disponibles.

Como referencia para la elaboración del diagrama se utilizará el ejemplo del caso de estudio **Sistema de Gestión de Talleres Mecánicos (MecaGest)** proporcionado para la actividad.

---

## Objetivo

Diseñar un diagrama que permita representar de manera clara:

- Los diferentes roles de usuario del sistema.
- Las responsabilidades principales de cada rol.
- Las acciones que puede realizar cada usuario.
- Las funcionalidades principales de la plataforma.
- La relación entre los roles y las funcionalidades del sistema.

El diagrama deberá permitir comprender rápidamente **quién utiliza la plataforma, qué puede hacer y qué funcionalidades tiene disponibles**.
